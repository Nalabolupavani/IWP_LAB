Experiment No. 02  XML Product Information Using XSLT

Objective

To develop an XML file containing product information and use XSLT to transform and display the XML data in a formatted HTML layout.


Project Information

This project demonstrates the use of **XML and XSLT** for storing and presenting product information.

The XML file stores structured product data such as product ID, name, category, price, quantity, and stock status. The XSLT file transforms this data into a professional and user-friendly HTML interface.

The project also includes CSS styling to improve the appearance and readability of the generated webpage.


 Technologies Used

- XML – Used to store product information
- XSLT – Used to transform XML data into HTML
- HTML – Used for the webpage structure
- CSS – Used for styling and presentation


Product Information

The XML file contains the following product details:

- Product ID
- Product Name
- Category
- Price
- Quantity
- Stock Status

---

Output

The XSLT stylesheet transforms the XML data into a formatted product inventory webpage.

The output displays the product information in a structured table with:

Product details
Price information
Available quantity
Stock status
Responsive design
Professional styling


How to Run
Download or clone this repository.
Open the project folder in Visual Studio Code.
Make sure products.xml and products.xsl are in the same folder.
Open the project using Live Server.
Open products.xml in the browser.
The XML data will be displayed using the XSLT stylesheet.

Result

The XML product information was successfully created and transformed using XSLT into a professionally formatted HTML webpage.
