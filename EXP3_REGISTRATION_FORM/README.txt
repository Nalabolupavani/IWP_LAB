Experiment No. 03   -  Registration Form with JavaScript Validation

Objective

To create a registration form with fields such as name, email, phone number, and password, and implement JavaScript for form validation.

## Project Information

This project demonstrates the development of a responsive registration form using HTML5, CSS3, and JavaScript.

The form collects basic user information and validates the entered data before submission. JavaScript is used to check the validity of the name, email address, phone number, password, and terms and conditions.

The interface is designed with a modern and responsive layout to provide a clean and user-friendly experience.

Technologies Used

- HTML5
- CSS3
- JavaScript

Features

- Responsive registration form
- Full name validation
- Email format validation
- 10-digit phone number validation
- Password validation
- Password strength indicator
- Terms and conditions validation
- Inline error messages
- Registration success message
- Responsive design for mobile and desktop


Form Fields

The registration form contains the following fields:

Full Name
Email Address
Phone Number
Password
Terms and Conditions
Validation

JavaScript validation is implemented for all important form fields.

Name
Cannot be empty
Must contain at least 3 characters
Should contain only letters and spaces
Email
Cannot be empty
Must follow a valid email format
Phone Number
Must contain exactly 10 digits
Only numeric values are accepted
Password
Must contain at least 6 characters
Must contain at least one uppercase letter
Must contain at least one number
Terms and Conditions

The user must accept the terms and conditions before registration.

Output

The webpage displays a modern registration interface with:

Registration form

Input validation
Error messages
Password strength indicator
Success notification
Responsive layout


How to Run

Download or clone this repository.
Open the project folder.
Open index.html in a web browser.
Using Visual Studio Code
Open the project folder in Visual Studio Code.
Open index.html.
Use the Live Server extension.
Select Open with Live Server.
The registration form will open in the browser.
Result

A responsive registration form was successfully created using HTML5 and CSS3, and JavaScript was implemented to validate the user input before submission.
