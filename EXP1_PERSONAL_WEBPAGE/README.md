Experiment 01 – Personal Webpage

Aim

To create a personal webpage using **HTML5, CSS3, and Bootstrap** that includes tables, lists, images, and multimedia controls.


Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons



Description

This project is a responsive personal webpage developed as part of **Experiment No. 1**.

The webpage demonstrates the use of HTML5 semantic elements, CSS3 styling, Bootstrap components, tables, ordered and unordered lists, images, and multimedia elements such as audio and video.

The design is responsive and can be viewed on desktops, tablets, and mobile devices.


 Features

- Responsive navigation bar
- Personal profile section
- Profile image
- Personal information table
- Ordered list
- Unordered list
- Technical skills section
- Skill progress indicators
- HTML5 audio player
- HTML5 video player
- Contact section
- Social media links
- Responsive Bootstrap layout
- CSS3 hover effects and transitions


HTML5 Elements Used

The following HTML5 elements are used in this project:

<nav> – Navigation bar
<header> – Profile/hero section
<section> – Different webpage sections
<table> – Personal details
<ul> – Unordered list of hobbies
<ol> – Ordered list of learning goals
<img> – Profile image
<audio> – Audio player
<video> – Video player
<footer> – Footer section

How to Run the Project
Using a Web Browser
Download or clone the repository.
Open the project folder.
Open index.html in any modern web browser.
Using Visual Studio Code
Open the project folder in Visual Studio Code.
Open index.html.
Install the Live Server extension.
Right-click index.html.
Select Open with Live Server.
